## Regra de ouro
Nenhum número inventado. Onde aparecer `[PREENCHER]`, o dado tem que vir do Strava, do Garmin ou da sua memória.

## Como publicar o site (uma vez só)
1. No GitHub, abra o repositório → **Settings** → **Pages**.
2. Em **Source**, escolha **Deploy from a branch**.
3. Branch: **main**, pasta: **/ (root)** → **Save**.
4. Em 1 ou 2 minutos o site fica em `https://joaomarcos1710.github.io/eujoaomarcosbomfim/`.

## Como editar pelo celular ou navegador
1. Abra o arquivo no GitHub e clique no lápis ✏️.
2. Troque o `[PREENCHER]` pelo dado real.
3. Clique em **Commit changes** e escreva o que mudou (ex.: `preenche data da prova`).
