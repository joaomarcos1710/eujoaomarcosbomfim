# Pilar Fé: ideias de textos

Textos curtos para Stories, Reels e posts que ligam fé e corrida.
Peso no perfil: **10%**, cerca de **1 por semana**. A fé aparece, mas o perfil não vira página religiosa.

## Regras
1. **O texto postado é seu.** Do livro, só a ideia. Nunca copie frases nem poste foto das páginas.
2. **Dê crédito quando a ideia for claramente do autor:** *"Inspirado no Bom Dia Amigo, de Israel Belo de Azevedo."*
3. **Versículo:** as ideias trazem só a referência. Use a tradução que você lê, com 1 versículo por peça.
4. **Corrida primeiro:** o texto tem que funcionar para quem corre, mesmo que a pessoa não seja cristã.
5. **Dados reais:** onde aparece `[PREENCHER]`, o número vem do Strava ou do Garmin.
